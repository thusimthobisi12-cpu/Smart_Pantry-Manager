Smart Pantry Manager

A Java Android app that helps reduce food waste. The user adds the
ingredients they have at home, and the app suggests only the recipes
they can cook using those ingredients.

Database
Room (SQLite). I chose it because the data is saved on the phone,
it works without internet, and it supports full CRUD.

Setup and run instructions
1. Install Android Studio.
2. Clone this repository.
3. Open the project in Android Studio and wait for Gradle to sync.
4. Run the app on an emulator or a real Android phone.
